## Overview

Xuanji-branch custom feature: add an "E2B 协议面" (E2B protocol plane) so that
clients speaking the E2B protocol can drive Substrate-managed sandboxes
(create/kill sandbox, command execution, filesystem access) without changing
the core actor lifecycle machinery. No product code exists yet (verified
2026-08-06: repo-wide search found no E2B implementation).
