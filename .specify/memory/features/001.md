# Feature Detail: Actor Lifecycle Management

**Feature ID**: 001
**Name**: Actor Lifecycle Management
**Description**: Create, delete, suspend, pause, and resume actors with sub-second activation via the control-plane API.
**Status**: Implemented
**Created**: 2026-08-06
**Last Updated**: 2026-08-06

## Overview

The core value proposition of Agent Substrate: full lifecycle management of
"actors" (agent-like workloads) mapped onto a smaller pool of ready "workers"
(Kubernetes Pods). The `Control` gRPC service in `ateapi` exposes
Create/Get/Update/Delete/List for actors plus SuspendActor, PauseActor, and
ResumeActor, enabling heavy multiplexing and instant actor teleport.

## Latest Review

Bootstrapped from repo inventory during feature-registry initialization

## Key Changes

1. Actor CRUD via `Control` gRPC service (`pkg/proto/ateapipb/ateapi.proto`).
2. SuspendActor / PauseActor / ResumeActor lifecycle transitions.
3. Atespace CRUD as the namespace/isolation resource for actors.
4. ListWorkers visibility into the worker pool.
5. DebugClear via the `Debug` service for development state wipes.

## Implementation Notes

- API server: `cmd/ateapi` (controlapi, scheduling, store packages).
- Upstream-owned capability — custom (xuanji) changes must stay separable per
  Constitution Principle I.
- Actor state transitions are coordinated with atelet and the ateom sandbox
  herders (see features 002, 003, 006).
- CLI surface: `kubectl ate create/delete/get/suspend/pause/resume actor`.

## Future Evolution Suggestions

- Richer lifecycle hooks (pre/post suspend callbacks).
- Actor priority classes for resume ordering under contention.
