# Feature Detail: GCP Provisioning & Install

**Feature ID**: 009
**Name**: GCP Provisioning & Install
**Description**: Idempotent GCP bootstrap (GKE, GCS, IAM, Monitoring) via tools/setup-gcp plus hack/install-ate.sh deployment and kind-based dev installs.
**Status**: Implemented
**Created**: 2026-08-06
**Last Updated**: 2026-08-06

## Overview

Deployment and provisioning tooling for the two supported environments:
`tools/setup-gcp bootstrap` idempotently provisions GCP resources (enables
APIs, creates the GKE cluster, GCS bucket, IAM bindings, and Cloud Monitoring
dashboards), and `hack/install-ate.sh` deploys the full system or individual
components from `manifests/ate-install/`. For local development,
`hack/create-kind-cluster.sh` + `hack/install-ate-kind.sh` run everything on
kind with valkey and rustfs.
