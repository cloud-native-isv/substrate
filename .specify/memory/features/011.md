# Feature Detail: OpenTelemetry Observability

**Feature ID**: 011
**Name**: OpenTelemetry Observability
**Description**: OpenTelemetry metrics/traces and Prometheus instrumentation across all components, with shared bootstrap, OTel config, and GCP dashboards.
**Status**: Implemented
**Created**: 2026-08-06
**Last Updated**: 2026-08-06
**Type**: Non-functional (DFO)

## Overview

All Substrate components ship with structured observability: a shared bootstrap
(`internal/serverboot/`) wires OpenTelemetry SDKs (otelgrpc/otelhttp
instrumentation, OTLP metric export) and Prometheus endpoints; the router
exposes routing metrics; manifests include otel-collector config; and
tools/setup-gcp provisions Cloud Monitoring dashboards. Operator guidance is in
docs/observability.md.

## Latest Review

Bootstrapped from repo inventory during feature-registry initialization
(2026-08-06). No end-to-end feature review has been performed yet.

## Key Changes

1. Shared OTel/Prometheus bootstrap (`internal/serverboot/`).
2. Router metrics (`cmd/atenet/internal/router/metrics.go`).
3. OTel collector config (`manifests/ate-install/ate-otel-config.yaml`).
4. GCP Monitoring dashboards (`tools/setup-gcp/dashboards`).
5. E2E metrics verification suite (`internal/e2e/collector_metrics.go`).

## Implementation Notes

- otelgrpc + otelhttp contrib instrumentation; OTLP gRPC metric exporter.
- E2E metrics suite asserts metrics emission, not just wiring.

## Future Evolution Suggestions
