## Overview

kubectl-ate is the operator-facing CLI (kubectl plugin) covering the full
user-facing surface: create/delete/get for actor, atespace, and workers;
suspend/pause/resume actor; actor logs; worker top; actor_snapshots listing;
and admin commands (make-ca-pool, make-jwt-pool, debug redis flush). Full
documentation lives in cmd/kubectl-ate/README.md.

## Key Changes

1. Actor/atespace/worker CRUD commands.
2. Lifecycle commands: suspend / pause / resume.
3. Observability commands: logs actors, top workers, actor_snapshots.
4. Admin commands: make-ca-pool, make-jwt-pool, debug redis flush.
5. Installable via `go install ./cmd/kubectl-ate`.
