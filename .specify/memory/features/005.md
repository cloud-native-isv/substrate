# Feature Detail: Worker Pool & CRD Controller

**Feature ID**: 005
**Name**: Worker Pool & CRD Controller
**Description**: Kubernetes controller reconciling ActorTemplate, WorkerPool, and SandboxConfig CRDs, with /scale subresource autoscaling.
**Status**: Implemented
**Created**: 2026-08-06
**Last Updated**: 2026-08-06

## Overview

atecontroller reconciles the declarative resource model: ActorTemplate
(workload definition), WorkerPool (pool of ready Pods with a `/scale`
subresource so Kubernetes pod autoscaling — e.g. HPA fed by
prometheus-adapter — can drive pool size), SandboxConfig (sandbox parameters),
and NetworkPolicy. Kubernetes handles infrastructure provisioning and worker
lifecycle while Substrate handles actor-specific scheduling.

## Key Changes

1. CRD types in `pkg/api/v1alpha1/` (ActorTemplate, WorkerPool, SandboxConfig).
2. Generated clientset/informers/listers (`pkg/client/`).
3. Controllers in `cmd/atecontroller/internal/controllers/`.
4. WorkerPool `/scale` subresource for HPA integration.
5. Manifests for CRD installation (`manifests/ate-install/`).

## Implementation Notes

- v1alpha1 API — no backward-compatibility guarantees at this stage
  (upstream status note).
- Autoscaling is deliberately delegated to Kubernetes primitives; see
  demos/autoscaled-workerpool.
