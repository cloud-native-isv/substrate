# draw-echarts 陷阱（Pitfalls）

> 从 viz-skill-arena 竞技 cycle（Substrate 架构图，2026-08-07）中 R1 评审实测发现的坑。每条含「现象 → 后果 → 规避」。最佳实践见 [best-practices.md](best-practices.md)。

## 1. 力导向图冒充组件架构图

**现象**：把系统组件关系画成力导向图，节点重叠、无子系统边界、无从属层次。
**后果**：作为「组件架构图」语义不达标（R1 两次点名），需求契合度被扣。
**规避**：架构视角用固定布局/分区背景；力导向仅作「关系视图」并明确标注。

## 2. 边标签全部常显

**现象**：25+ 条边的 edgeLabel 默认全部显示。
**后果**：密集区标签与节点互相遮挡，图不可读。
**规避**：默认隐藏、悬停显示；或 labelLayout 避让；或按类型分组着色。

## 3. 数据/配置内嵌单 HTML

**现象**：图数据与配置全部内嵌进一个 HTML 文件。
**后果**：重生成/改图需手工编辑大文件，可维护性差，reproducibility 降分。
**规避**：数据外置 `*.config.js` / `*.config.json`。

## 4. [*] 伪节点渲染为空圆

**现象**：状态机起止节点用 category 3 但 label formatter 返回空串。
**后果**：开始/结束节点无法辨识，状态机语义残缺。
**规避**：起止节点显示 `[*]` 或「开始/结束」文字。

## 5. 状态机节点不着色

**现象**：仅边按绿/黄/红/灰着色，节点框全部同色。
**后果**：状态类别（稳态/迁移/异常）无法一眼区分，图例与图不对应。
**规避**：节点描边/填充同步随状态类别着色，并与图例对应。

## 6. 依赖 CDN 导致离线空白

**现象**：HTML 通过 `<script src="https://cdn.jsdelivr.net/npm/echarts@5/...">` 加载。
**后果**：离线/内网环境图完全空白，不可复现。
**规避**：锁定版本 + 本地 vendored 副本回退。

## 7. 需求图缺失且不说明

**现象**：任务要求部署架构图，交付时仅以关系图近似覆盖，无任何说明。
**后果**：评审按「需求覆盖不全」扣分（R1 点名）。
**规避**：逐项核对交付清单；缺图时显式说明取舍。

## 8. 标题/图例/脚注信息重复

**现象**：图内 title 与 HTML 容器标题一致，图例与正文说明重复。
**后果**：图面冗余、信息重复。
**规避**：每类信息只出现一次。

## 9. vendor/ 空目录 + document.write 回退

**现象**：HTML 引用 `vendor/echarts.min.js` 但 vendor/ 为空，加载器用 document.write 回退 CDN。
**后果**：离线/内网环境图全空白（R1 点名：*"离线打开 HTML 无法渲染"*）；document.write 阻塞解析且被 CSP 拦截。
**规避**：交付前真实放置 vendor/echarts.min.js（`scripts/vendor-echarts.sh`），加载器改为本地优先 + CDN `onerror` 动态回退；`verify-deliverable.mjs` 检查。

## 10. 交付无静态渲染产物

**现象**：只有 HTML（依赖 CDN），无 PNG/SVG 快照。
**后果**：评审离线无法核验实际效果，只能看到空白（R1 点名）。
**规避**：交付附 `chart.getDataURL()` / toolbox 保存 / headless 截图导出的 PNG/SVG。

## 11. 推断边与源描述边同样式

**现象**：RUNNING 直出 DELETE、CRASHED 人工 Delete 等补全语义只用脚注说明，边样式与源描述边相同。
**后果**：推断与事实边界不直观，评审误读为源描述原文（R1 点名）。
**规避**：补全边虚线灰、人工介入边红色虚线、源描述边实线，图内图例/subtext 说明。

## 12. config.js 与 config.json 手工同步

**现象**：双副本标注 "keep both in sync" 但靠手工维护。
**后果**：任一侧漏改即漂移，HTML 与校验结果不一致（R1 点名）。
**规避**：JSON 为唯一权威，JS 包装由 `scripts/sync-config.mjs` 生成；`--check` 模式防漂移。

## 13. 多图色板散落各 config

**现象**：多图共用暗色主题，但每份 config 各自硬编码 hex 色板。
**后果**：跨图视觉不一致，改主题需逐文件改（R1 点名）。
**规避**：共享 `window.DESIGN_TOKENS` 对象，各 config 引用。

## 14. 固定坐标无校验

**现象**：手写固定坐标 graph 节点/分区无越界/重叠检查（18 节点挤 900px 画布）。
**后果**：长期维护后节点重叠、出画布，图不可读（R1 点名）。
**规避**：meta 记录画布尺寸与栅格规则；交付前跑 `scripts/check-layout.mjs`。

## 15. 校正源描述无依据

**现象**：资源分层图「保真校正」（CRD→per-tenant Etcd）与任务简述/mermaid 解读冲突，未附校正出处。
**后果**：仲裁不可复核，评审无法判断哪侧为准（R1 点名）。
**规避**：新旧两段同时呈现并标注时间点；交付说明附校正依据；分区用「已迁移/演进」措辞。
