# Agent 知识页契约（agent page contract）

manage-agents 的意图页（运维/诊断/装配）引用「Agent 知识页」承载具体 Agent
的实操细节。知识页由部署环境的配套技能（如本机前门技能）提供，文件名形如
`agents/<agent>.md`。通用意图页只依赖如下结构——缺了对应小节时按「未知，
先只读探测」处理。

## 必备小节

1. **组件与进程**：组件、进程/常驻方式、端点、日志位置；
2. **配置地图**：配置文件路径、作用、修改注意（备份/权限位/禁改项）；
3. **变更协议**：该 Agent 特有的干跑命令、重启命令、回归命令
   （通用流程见 intents/agent-ops.md，本页只写差异）；
4. **禁区**：凭据值、不可改的安全姿态、钉版声明等；
5. **已知坑**（可选）：实测过的故障与规避。

诊断型知识页另加：**判读决策表**（签名 → 根因归属 → 处置）与**场景记录规范**
（新形态如何沉淀）。

## 分层纪律

知识页是 L2 内容：一次任务只装载目标 Agent 的一页；全量遍历是反模式。
