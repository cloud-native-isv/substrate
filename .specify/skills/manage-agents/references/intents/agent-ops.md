# 意图：组件运维（agent ops）

对某个 Agent 组件（进程/端点/配置/插件）执行查看与修改。通用变更协议如下；
各 Agent 的组件地图、命令与禁区由部署方的配套技能（agent 知识页）提供，
页面结构契约见 [../agent-page-contract.md](../agent-page-contract.md)。

## 通用变更协议

1. **备份**：`cp <file> <file>.bak-$(date +%Y%m%d%H%M%S)`
2. **干跑**：使用该 Agent 的离线验证手段（配置 dump / 解析预检），没有就干跑解析
3. **应用**：最小编辑，保持既有注释结构
4. **重启**：用该 Agent 自己的重启命令（各 Agent 机制不同，勿混用）
5. **回归**：组件级健康检查（端点可达 / CLI 冒烟 / 关键配置回读）
6. **记录**：向部署方的运维日志追加一条（日期/操作方/目标/变更/验证/回滚路径）
7. **禁区**：凭据值一律不改；各 Agent 专属禁区见其知识页

## Agent 知识页的获取

本技能不内置任何具体 Agent 的知识页——它们由部署环境的配套技能
（如本机前门技能）按 [agent-page-contract.md](../agent-page-contract.md) 提供。
未找到目标 Agent 的知识页时：先只读探测该 Agent，沉淀后再建页。
