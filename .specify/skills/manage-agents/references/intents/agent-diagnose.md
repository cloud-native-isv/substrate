# 意图：异常诊断（diagnose）

排查某个 Agent 无响应、卡住、报错的根因归属（应用本身 / 模型服务 / 传输链路）。

## 通用诊断循环（只读优先）

1. **采集证据**：先跑该 Agent 知识页指定的采集脚本（若有），只采集不判断；
2. **分水岭判据**：先回答「模型近期是否成功回过」——区分间歇性与全断；
3. **按失败形态归因**：对照该 Agent 知识页的判读决策表定位根因归属；
4. **输出结论**：一句话结论 + 证据引用 + 处置建议（标注哪些需用户授权）；
5. **沉淀**：新故障形态按该 Agent 知识页的场景记录规范追加。

**红线**：诊断默认只读——不重启、不删会话、不改配置；修复动作必须先向用户
说明再执行。

Agent 知识页由部署环境的配套技能提供（契约见
[../agent-page-contract.md](../agent-page-contract.md)）；没有对应知识页时，
先只读探测、沉淀后建页。
