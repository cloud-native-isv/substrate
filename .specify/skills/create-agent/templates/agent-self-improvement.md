## Self-Improvement Contract

- **Subject**: this persistent Agent Template or Instance; the canonical definition file is the only editable owner. A live Agent Execution is evidence, not a definition.
- **Observe**: after a completed substantial execution, use its logs/result manifest, user corrections, and scoped feedback as candidate signals.
- **Improve**: follow `.specify/shared/workflow/self-improvement-workflow.md`; route qualified changes through `improve-agent` with the target layer explicit.
- **Boundary**: do not mutate the governing definition mid-run, widen permissions/territory, or weaken safety rules through Self-Improvement.
- **Verify**: use a fresh execution for behavior-changing validation and keep the outcome pending until a later comparable run supports it.
