# draw-d3js 陷阱（Pitfalls）

> 从 viz-skill-arena 竞技 cycle（Substrate 架构图，2026-08-07）中 R1 评审实测发现的坑。每条含「现象 → 后果 → 规避」。最佳实践见 [best-practices.md](best-practices.md)。

## 1. 力导向边标签全部常显

**现象**：33 条边的标签全部常显（10px 小字），与节点/连线密集重叠。
**后果**：图面混乱，可读性差，视觉分被扣。
**规避**：默认隐藏、悬停显示；或按 type 分组着色 + 精简标签。

## 2. 非组件概念混入组件图（伪节点）

**现象**：把「请求 parking」这类机制概念作为节点画进组件图。
**后果**：语义误导——parking 不是组件，评审点名 *"伪节点，语义上会误导"*。
**规避**：机制/行为概念移入说明文字或单独标注，不混入组件节点。

## 3. 基础设施节点归入业务子系统

**现象**：存储类节点（Valkey/CRD/GCS）被归入控制面/资源模型等子系统分组。
**后果**：基础设施语义被掩盖，分层关系表达错误。
**规避**：存储/基础设施独立分组，配独立图例色。

## 4. 随机初始布局

**现象**：力导向图无 seed/预设坐标，每次打开布局不同。
**后果**：不可复现、不可对比（R1 点名），reproducibility 降分。
**规避**：固定布局预设或记录初始坐标。

## 5. 数据内嵌单 HTML

**现象**：nodes/links/rels 全部内嵌进一个 HTML 文件。
**后果**：维护性差、改图需手工编辑大文件；CDN 依赖致离线不可用。
**规避**：数据抽离独立 `data-*.js` + 本地 vendor d3。

## 6. 长标签旋转极限挤压

**现象**：热力图列头 -32° 旋转的长标签（如 ate-api-server）与窄单元格宽度冲突。
**后果**：标签截断/重叠，列语义不清。
**规避**：缩短展示名 + tooltip 全名，或增大列头区。

## 7. 图例无色块

**现象**：力导向图只有右上角文字图例，无颜色样本。
**后果**：读者无法把颜色映射到分组含义。
**规避**：图例带色点/色块。

## 8. 需求图型缺失

**现象**：任务要求 5 类图，只交付力导向/状态机/热力图 3 类，缺序列图与资源模型分层图。
**后果**：需求覆盖不全（R1 点名），requirement-fit 降分。
**规避**：绘制前按需求清单核对图型；缺失图型用可表达的替代视图或树图补齐，并说明取舍。

## 9. 无复现附录 / 数据维护入口不明

**现象**：交付 HTML 无显式「重新生成」说明，data-*.js 维护方式只存在于代码注释。
**后果**：评审/接手者不知如何改数据或重渲染，可复现性降分（R1 点名）。
**规避**：HTML 附复现附录（可见折叠页脚 + 文件头注释块），说明各数据数组对应图面哪部分。

## 10. 矩阵强度值无标尺

**现象**：依赖矩阵强度 0-4 无定义，评审无法判断 3 与 4 的差别。
**后果**：主观赋值不可解释、不可复现（R1 点名）。
**规避**：数据文件头 + 图注给出评分标尺（如 4=强同步依赖 / 1=弱关联）。

## 11. 推断路径混同源描述

**现象**：作者推断的恢复路径（如 FAILED→SUSPENDED 冷启重建）未标注来源，读者误以为源描述如此。
**后果**：语义误导，评审无法区分事实与推断（R1 点名）。
**规避**：推断迁移/状态用区别样式 + 「描述未定义，推断路径」标注，恢复路径在图例/侧栏显式列出。

## 12. 手工坐标无栅格/校验

**现象**：固定坐标节点增删后重叠、越界。
**后果**：图面污染，后续维护无法安全改布局。
**规避**：数据文件头记录坐标分区栅格规则 + 渲染前重叠/越界校验。

## 13. 边标签锁死悬停态

**现象**：边标签只悬停显示，无「常显」开关，静态打印/截图信息缺失。
**后果**：文档嵌入时图信息不全（R1 点名）。
**规避**：提供「常显边标签」开关，导出时切换为常显。
