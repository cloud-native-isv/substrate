# 层参考：项目概览 —— 项目的目标是什么

对应报告 `## 项目概览` 节。面向外部读者回答第一层问题：**这个项目为什么存在？目标是什么？边界在哪里？** 工作流主框架见 [../SKILL.md](../SKILL.md)；跨层公共约定（报告骨架、刷新规则、一致性清单）见 [reporting-playbook.md](reporting-playbook.md)。

## 呈现要素

| 要素 | 内容 | 形态 |
|------|------|------|
| 背景 | 项目为什么启动、解决什么问题 | 1–2 段纯 Markdown 叙述 |
| 目标 | 项目要达成的业务成果，1–3 条 | 条目列表，每条注明出处 |
| 范围 | 做什么（in scope）/ 不做什么（out of scope） | 两组条目列表 |
| **整体进度摘要（强制）** | 项目当前做到哪了：整体完成度、一句进度判断、进度概览（工作项分布 / 里程碑达成 / 逾期情况） | 章节末固定小节 `### 整体进度摘要`：完成度句 + 判断句 + 四行进度概览表 + 进度条（引擎给 `progress_bar` 则必出、未给则不出） |

## 整体进度摘要（本层的进度呈现位）

外部读者读完"项目是什么"之后立刻要问"做到哪了"，因此**进度摘要固定放在本章节末尾**，是本层的强制要素（与背景/目标/范围同级必做）：

- **模板与字段引用**：完整模板见 [progress-presentation.md](progress-presentation.md) 3.1；四行概览表分别承载整体完成度（含分子分母与分母口径）、工作项三态分布、里程碑达成情况、逾期情况。
- **数字一律"取引擎输出字段"**：完成度、计数、达成率、逾期条目数与天数都引用进度引擎的项目级汇总字段，**本节不做任何计算**——不写除法算式、不比较日期、不算天数差。
- **判断句由枚举查表得出**：排期判断句取引擎的排期状态枚举并按 [progress-presentation.md](progress-presentation.md) §4.2 映射为固定措辞（如"进度贴合计划"/"落后于计划（最长逾期 N 天）"/"无排期依据，进度未与计划比对"），**不得**由百分比自行推断措辞。
- **缺数据不缺位**：进度字段为空值时保留小节与表行，写 `-（无可计数依据）` 并配材料声明句，**绝不写 `0%`**（降级细则见 [progress-presentation.md](progress-presentation.md) 第 6 节、[degradation.md](degradation.md) 第 3 节）。
- **业务语言**：摘要面向外部读者，只出现数值与业务措辞，不出现字段名、脚本名与内部编号。

## 取材优先级（表单主源 → 上下文 → opt-in repo 佐证）

本层的字段主源是**项目输入表单**（`project.project_name` / `project_desc` / `baseline_date`，见 [required-info.md](required-info.md)）；背景与范围叙述来自上下文摄取。优先级：

| 优先级 | 信息源 |
|--------|--------|
| 1（主源） | 表单 `project` 段：`project_name`（R）、`project_desc`（O）；及 `sources[]` 声明的管理系统导出/立项文档 |
| 2 | 当前对话上下文与用户提供的外部材料（立项书、项目章程、周报、需求文档的背景节） |
| 3（仅 opt-in） | 已授权 `project.project_desc` 时的 repo 定向佐证：语言清单 `description` → README Introduction（见 [source-tiers.md](source-tiers.md) §1.1） |

三者皆无 → 背景写「材料未记录」并列出已检索来源（[degradation.md](degradation.md) §2.3），**不编造背景**。

## 提炼规则

- **业务语言**：目标写成业务成果（"让 X 用户能够 Y"），不写内部代号与技术实现细节。
- **目标 ≠ 范围**：目标是要达成的成果，范围是工作边界；两者分开呈现，不混写。
- **可溯源**：每条目标必须能指回具体材料（文件+章节）；材料没有明说目标时，宁可发起澄清或显式标注"推断自 <出处>"，绝不编造。
- **读者一分钟读完**：全节控制在一屏内；背景不超过两段，目标不超过 3 条。
- **口径对齐**：本节提到的阶段/特性名称与后续各层（需求与特性、功能分解）逐字一致。

## 落笔检查

- [ ] 背景、目标、范围三要素齐全（材料缺失的要素显式说明缺失）
- [ ] **`### 整体进度摘要` 小节在位**：完成度句（含分子分母与分母口径）+ 判断句 + 四行进度概览表齐全；数值逐个取引擎输出字段，本节无除法算式、无日期比较、无自算天数
- [ ] 进度字段为空值时写 `-（无可计数依据）`（非 `0%`）并有材料声明句；判断句由排期状态枚举查表得出，未由百分比自行推断
- [ ] 摘要中的完成度、计数、达成率、逾期数与《任务进展》《项目里程碑》各处**同值同源同精度**
- [ ] 每条目标有出处；推断性内容已显式标注
- [ ] 无内部黑话；外部读者不读代码也能看懂
- [ ] 篇幅一屏内
