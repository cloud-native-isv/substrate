# Step 2: 选图类型 + 选生成路径

Excalidraw 是自由画布，没有"图类型"的语法区分——但有两条生成路径，选型决定成功率。

## 路径对照表

| 图表类型 | 推荐路径 | 理由 |
|---------|---------|------|
| 流程图（flowchart） | **Mermaid 桥接** | 自动布局 + 文本绑定，`flowchart TD/LR` |
| 时序图（sequence） | **Mermaid 桥接** | `sequenceDiagram`，生命线/消息全自动 |
| 类图 / ER 图 | **Mermaid 桥接** | `classDiagram` / `erDiagram` |
| 状态图 | **Mermaid 桥接** | `stateDiagram-v2` |
| 架构图 / 拓扑图 | **场景 JSON 直出** | 需要分区、层叠、自定义位置，Mermaid 表达不了 |
| 思维导图 / 树形展开 | **场景 JSON 直出**（简单树也可 Mermaid `mindmap`） | 需要控制分支间距与配色时用直出 |
| 组织结构图 | 场景 JSON 直出（或 Mermaid 不支持时直出） | 层级 + 横向对齐 |
| 时间线 / 泳道 / 任何版面定制 | **场景 JSON 直出** | 自由画布的主场 |

## Mermaid 桥接的边界

- 支持 Mermaid 的图类型优先走桥接：LLM 写 Mermaid 语法的正确率远高于手写坐标。
- 桥接产物是**标准 .excalidraw 场景**（经 `convertToExcalidrawElements` 规范化），可以继续手工微调。
- 桥接限制：颜色/样式控制有限（黑白手绘风为主）；节点过多时版面不可控——超过 ~15 个节点考虑直出或拆图。
- **Mermaid 语法注意**：节点文本含中文/特殊字符时用 `["文本"]` 引号形式；边标签用 `-->|标签|`。

## 直出路径的边界

- 元素数量建议 ≤20（含文本）；更多则拆图集（概览 + 下钻）。
- 直出必须走完 Step 3（实现 SDS 几何 / 无 SDS 时兜底规划）——不要边写边想坐标。

## 决策口诀

> 带 SDS geometry 的委派 → **必须直出**（桥接自动布局兑不了 SDS 坐标，属未声明偏离）；结构标准、版面无所谓 → Mermaid；版面有要求、结构自由 → 直出；拿不准 → 先 Mermaid 出草稿，不满意转直出微调。
