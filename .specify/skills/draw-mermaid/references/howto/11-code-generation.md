# 代码生成（11-code-generation）

## 1. 草拟流程

1. 按 Step 1 上下文摘要列出元素与关系（先纸面后代码）；
2. 定图类型与方向（Step 2/4）；
3. 写代码骨架：首行图类型声明 → 元素声明 → 关系声明；
4. 加入 init 配置与 classDef（Step 7 样式）；
5. 渲染 → 读图 → 微调（Step 8）。

## 2. 标签与注释规则

- **元素标题 ≤10 字符（CJK）/ ≤12 字符（英文）**；
- 标题先去重（类型/嵌套已表达的删掉）；
- 详细说明外置：
  - 边标签 `A -->|说明| B`（≤10 字符）；
  - note（sequenceDiagram `Note`、classDiagram `note for`）；
  - legend（flowchart `legend` 指令）；
- 禁止内联字号/加粗（字号层级见 guide/style.md §1）。

## 3. 代码组织习惯

- 一个文件一张图：`figure-<NN>-<slug>.mmd`；
- 文件内顺序：`%%{init}%%` → 图类型声明 → 元素（含 classDef）→ 关系；
- 关系集中声明（元素声明之后），便于检查方向与缺失；
- 图集共享 init 段与 classDef 段（复制粘贴保持同义）。

## 4. 配套文字准备

- 每图配「标题 + 一句说明」（HTML 文档用）；
- 图集配索引段与交叉引用（`▶ 见图N`）；
- 复杂语义在文字中展开，图内保持干净。

## 5. 自检（编码完成、渲染之前）

- [ ] 首行图类型正确？init 在首行之前？
- [ ] 元素 id 用引号包裹中文/特殊字符？
- [ ] 关系方向正确（依赖/继承/基数）？
- [ ] 标签 ≤10 字符、无句子？
- [ ] 核心元素 ≤7、总 ≤15？
- [ ] classDef 与主题统一？
