# UML 概述（01）

> UML（Unified Modeling Language）是软件建模的标准语言。Mermaid 覆盖 UML 的四个常用图类型（类图、时序图、状态图、用例图近似），本技能用 Mermaid 表达 UML 语义。

## 1. UML 图表分类

**结构图**（静态）：
- 类图（classDiagram ✓）、对象图（classDiagram 近似）、包图（flowchart/namespace 近似）、组件图（flowchart/C4 近似）、部署图（flowchart/C4 近似）、复合结构图（无匹配）

**行为图**（动态）：
- 用例图（flowchart 近似）、活动图（flowchart ✓ 映射）、状态机图（stateDiagram-v2 ✓）、时序图（sequenceDiagram ✓）

## 2. UML 建模原则

1. **单一视角**：一张图只表达一种视图（结构 vs 行为）；
2. **语义正确**：关系类型、基数、构造型必须符合 UML 语义；
3. **面向读者**：图为读者服务（评审/汇报/教学的对象不同，抽象层级不同）；
4. **可追踪**：模型元素可追溯到需求/代码（上下文摘要）。

## 3. UML 在软件工程中的角色

- 需求阶段：用例视图界定范围；
- 设计阶段：类图/时序图/状态图固化设计决策；
- 实现阶段：类图指导代码结构；
- 文档阶段：架构图集（C4）对外沟通。

## 4. Mermaid 的 UML 语义边界

Mermaid 是轻量 DSL，不是完整 UML 工具：
- 支持：类关系六种、时序片段、状态守卫/复合、ER 基数；
- 不支持：OCL 约束、完整 profile 机制、复合结构、时序波形——这些场景需在文字中补充语义或改用专业 UML 工具。
