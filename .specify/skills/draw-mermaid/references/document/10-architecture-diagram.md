# 架构图设计（10）

## 1. 架构视图

- **逻辑视图**：类图/组件图（结构）；
- **过程视图**：时序图/活动图（行为）；
- **部署视图**：部署图（拓扑）；
- **数据视图**：ER 图（持久化）；
- **场景视图**：用例近似（需求）。

## 2. C4 模型

| 层级 | 问题 | Mermaid |
|------|------|---------|
| Context | 系统在环境中的位置 | C4Context |
| Container | 系统由哪些可部署单元组成 | C4Container |
| Component | 容器内组件 | C4Component |
| Deployment | 部署在哪 | C4Deployment |

- 从上到下逐层递进；边界名称跨层一致；
- 每层回答不同读者的问题（干系人/架构师/开发者/运维）。

## 3. 视图视角（4+1 模型）

1. **场景视角**（用例）：驱动其他视图；
2. **逻辑视角**：类图/组件图；
3. **过程视角**：时序/活动图；
4. **开发视角**：包图（模块组织）；
5. **物理视角**：部署图。

## 4. 架构图集组织

```mermaid
flowchart TD
  subgraph 图集
    A1[C4Context 总览]
    A2[C4Container 容器]
    A3[C4Component 组件]
    A4[时序图 关键交互]
    A5[部署图 拓扑]
  end
```

- 概览图在顶，下钻图引用（`▶ 见图N`）；
- 共享词汇：系统名/颜色/编号跨图一致；
- 每图自足（diagram-principles §4.3）。

## 5. 绘制要点

- 架构图是决策记录：标注关键决策（边标签/note/图集文字）；
- 平衡抽象：每图 ≤15 元素，层级 ≤3；
- 架构图≠现状图：明确视角（现状/目标/差距）。
