# Token 效率纪律(Token-Efficiency Discipline)

> **Single Source of Truth**: 本文档是框架 Token 使用效率纪律的唯一定义处(Feature 040,spec `035-token-efficiency`)。任何命令、技能、代理或共享工作流引用本纪律时 MUST 以路径引用本文件,MUST NOT 复制规则文本。经 `.specify/instructions.md`(由 `templates/instructions-template.md` 生成)ambient 生效于全部 `/speckit.*` 流程。

随着框架流程增多,每次运行注入大模型上下文的内容量(Token 消耗 + 上下文污染)是框架级质量属性。三条纪律:**程序优先**、**摘要优先**、**消耗观察**。

## 程序优先(Program-First)

凡可用**固定规则**表达的文本/数据判断——模式匹配、结构校验、计数、去重、排序、比对——框架流程 MUST 交由确定性程序(脚本/引擎/正则)执行,MUST NOT 将原文送入大模型进行该类判断。大模型只接收程序产出的**判定结果或摘要**。

- 执行面 MUST 优先复用既有引擎与 Tool 记录(见 `.specify/shared/workflow/tool-reuse-gate.md`,宪法原则 XII);无现成能力时新写脚本即是预期产出。
- 典型正例:用 `grep`/引擎 action 判断文件是否含某字面量;用 `wc` 计数;用 `diff -q` 比对镜像。典型反例:把整份文档粘入上下文让模型"看看有没有 X"。

## 摘要优先(Summary-First)

框架流程 MUST NOT 把**机器管理数据文件**(反馈存量、记忆存量、证据产物、历史库、运行工件、清单/索引、日志等)的原文整体注入大模型上下文。例行访问 MUST 消费摘要、字段投影或定向节选(引擎 list/recall/stats 类输出、`grep` 行投影、`head`/区段读取)。

原文整读仅限例外情形:

- **(a)** 该文件是当前**编辑目标**(读后改,含工具的 read-before-edit 约束);
- **(b)** 文件低于**小文件阈值**(见下节);
- **(c)** 沿升级阶梯逐级升级且**记录理由**。

注意:本禁令约束的是**注入大模型上下文**;程序侧(脚本/引擎)读取原文不受限——程序读原文、模型读摘要,正是程序优先与摘要优先的协同方向。

## 升级阶梯(Escalation Ladder)

数据访问按三级逐级放宽,MUST NOT 跳级(例外 (a)(b) 可直接整读):

1. **摘要**:引擎摘要/查询输出、索引行、frontmatter 投影;
2. **定向节选**:按行号/区段/匹配上下文读取所需片段;
3. **有界整读**:确认摘要与节选不足以支撑决策后整读,并记录升级理由(一句话即可,落在当次流程的产物或反馈中)。

摘要失真导致错误决策的风险由阶梯本身对冲:允许升级,但升级要留痕。

## 小文件阈值

默认阈值:**≤ 100 行** 且 **≤ 10 KB**(双条件同时满足)时允许直接整读。本节是该阈值的**唯一定义点**,他处仅引用;具体场景可显式声明覆盖值(声明处生效,不回写本节)。

## 判定边界

- **语义级判断归大模型**:需要理解含义、权衡取舍、跨上下文综合的判断(如"这段措辞是否偏离意图")无法用固定规则表达,MUST 交大模型,纪律不强制程序化——过度应用会损害质量。
- **存疑时**:允许大模型判断,并可将该情形作为 Token 观察记入反馈,供后续论证是否可程序化。
- **计数不产生结论**:程序产出的计数/匹配信号只作路由与证据,复杂决策仍归大模型(与证据纪律"计数只路由不产生发现"同向)。

## 消耗观察(Consumption Observation)

以既有 Feedback 机制为载体(见 `.specify/shared/workflow/feedback-step.md` Reflect 步骤),wrap-up 自评三问:

1. 本次是否发生**原文转储**(机器管理数据文件整体入上下文)?
2. 是否有**LLM 代做确定性工作**(固定规则判断未交程序)?
3. 是否**重复读取**同一内容?

有发现 → 对应优化点条目行 MUST 内嵌字面量 **`token-efficiency`**(稳定标记,供 `feedback-utils.py --action list --contains token-efficiency` 检索聚合与证据 feedback 泳道消费)。干净运行 MUST NOT 追加空洞观察条目。量化口径:定性描述或注入量代理指标(行/字节,仅用于同一流程前后对比);精确 Token 计数不可得时 MUST **不编造**具体数值。
