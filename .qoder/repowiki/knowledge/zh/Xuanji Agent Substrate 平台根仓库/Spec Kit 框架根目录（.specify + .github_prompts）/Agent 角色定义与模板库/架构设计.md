本模块是纯声明式配置目录，按职责分为三个子目录：`templates/` 存放每个 Agent 的 `.agent.md` 模板文件，采用 YAML frontmatter 声明 `name/description/user-invocable/supervisor/capacity-scope/model/tools/skills/maxTurns/color` 等元数据，正文描述角色职责、上下游契约、EEI（Executor-Evaluator-Optimizer）监督循环、评分维度与可用 Skills；`instances/` 为运行时实例占位目录（当前为空，供动态生成具体 Agent 实例使用）；`execution/{configs,logs,scripts}/` 为执行期产物目录（配置、日志、脚本），由上层编排器在运行期间写入。依赖方向单向：Agent 模板仅通过 `skills/*` 引用外部能力，不反向依赖项目源码，从而保持 Agent 定义的独立性与可移植性。
