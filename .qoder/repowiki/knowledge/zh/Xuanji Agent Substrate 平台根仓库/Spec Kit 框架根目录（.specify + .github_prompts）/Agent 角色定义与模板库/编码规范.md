- 每个 Agent 模板统一以 YAML frontmatter 开头，声明 name、description、user-invocable、supervisor、capacity-scope、model、tools、skills、maxTurns、color 等元数据字段。
- 正文固定包含 Role/Stages/Type、Identity & Responsibilities、Project Context、Workflow、Upstream/Downstream、Output Format、Supervision & EEI Delegation、Skill Enablement 等章节。
- 通过 `capacity-scope` 字段将 Agent 绑定到唯一的能力域标识，供调度器按角色路由。
- 默认启用 `supervisor: true`，使 Agent 以 EEI 三阶段（Executor/Evaluator/Optimizer）监督循环方式产出结果，仅在显式设为 false 时退化为单次输出。
- Skills 列表限定为角色相关的最小集合并附用途说明，优先调用框架内置 skill 而非手写实现。
