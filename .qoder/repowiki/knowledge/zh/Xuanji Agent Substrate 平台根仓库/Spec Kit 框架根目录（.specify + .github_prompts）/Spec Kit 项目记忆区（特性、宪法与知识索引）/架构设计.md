该模块是 `.specify` 工作流框架的持久化记忆层，按职责划分为四个子目录：
- `features/`：每个功能一个编号 Markdown 文件（001–018），由根级 `features.md` 表格索引；每个详情文件内置统一的「Status Tracking」状态机（Draft → Planned → Implemented → Ready for Review → Completed），被 `/speckit.feature`、`/speckit.plan`、`/speckit.implement` 等命令引用为唯一真相源。
- `constitution.md`：项目宪法，定义上游优先双分支纪律、文档优先、代码即真相、测试先行、CI 门禁等原则及版本治理规则，作为所有计划与变更的合规检查基线。
- `session/`、`feedback/`、`knowledge/`：各自通过 `index.json` 元数据索引本目录下的 Markdown 条目，分别记录 Speckit 指令执行会话、命令运行反馈和领域约定/用户决策，形成可检索的知识资产。
依赖方向单向：上层 `/speckit.*` 命令读取并更新这些文件，模块自身不反向依赖源码实现，仅通过 `Related Files` 与 `Latest Review` 段落与代码仓库建立引用关系。
