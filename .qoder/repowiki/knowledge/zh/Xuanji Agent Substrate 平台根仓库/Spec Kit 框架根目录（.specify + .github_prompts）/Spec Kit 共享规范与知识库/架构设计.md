本模块以 `.specify/shared/` 为根，按职责划分为五个并列子目录：`definitions/` 提供 Agent Template/Instance/Execution 三层模型、Subagent、Tool、Goal 等概念的权威术语表；`workflow/` 描述各技能步骤（docs/evidence/feedback/interview）的执行流程、运行时模式检测（project vs standalone）、工具复用门禁与用户输入协议；`patterns/` 沉淀可复用的对话与协调模式（interview/reconcile）；`guidelines/` 给出需求编写、清单方法论、token 效率等写作规范；`constants/` 存放分类法、DFX 目录与忽略规则等静态常量。`.specify/docs/` 用于存放按时间戳命名的项目级计划与审计记录，与共享规范解耦。所有文档均为 Markdown，通过相互引用形成单一事实源，被上层 skills、agents、teams 等命令消费而不引入代码依赖。
