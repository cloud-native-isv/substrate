- 所有 AI 指令与工具入口统一指向 `.specify/instructions.md`，其他工具可见路径仅作为符号链接存在，禁止复制副本。
- Agent 采用 Template → Instance → Execution 三层结构，Template 存放于 `agents/templates/`，Instance 存放于 `agents/instances/`，Execution 配置与日志分置于 `agents/execution/`。
- Skill 以 `SKILL.md` 描述元数据并配合 `references/` 与 `scripts/` 目录组织，安装后位于 `.specify/skills/<name>/`。
- 文档模板与 GitHub Prompts 均以 Markdown frontmatter 声明类型、参数与用途，由 `/speckit.*` 命令按需渲染或注入。
- 可复用资源（Agent/Skill/Tool）在 `instructions.md` 末尾的对应注册表区域登记，保持去重与排序，供命令自动发现。
- 跨子模块共享的概念、工作流与模式指南集中放在 `shared/`，各子模块通过引用而非复制来保持一致性。
