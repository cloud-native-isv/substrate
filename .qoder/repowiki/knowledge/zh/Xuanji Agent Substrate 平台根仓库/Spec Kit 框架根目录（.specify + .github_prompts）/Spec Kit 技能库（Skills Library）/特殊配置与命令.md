各技能自包含安装步骤：`browser-utils` 需 `npm run setup` 安装 Playwright 并预检模块加载；`database-utils` 需 `pip install -r requirements.txt` 并复制 `connections.example.json` 为 `connections.json`；`draw-mermaid` / `draw-plantuml` 依赖外部 `mermaid-cli` 或 `mermaid.ink` 服务器；`document-utils` 需要 LibreOffice (`soffice`) 用于 PPTX/DOCX 转换。
