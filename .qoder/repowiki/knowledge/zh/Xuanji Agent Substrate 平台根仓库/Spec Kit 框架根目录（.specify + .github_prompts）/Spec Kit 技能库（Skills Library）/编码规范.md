- 每个技能以 `SKILL.md` 的 YAML front matter 声明 `name`、`description`、`skill_id`、`license`、`metadata` 等元数据，作为被引擎加载的统一契约。
- 技能内部资源统一通过 `${SKILL_HOME}` / `${SKILL_WORKDIR}` 环境变量引用，禁止硬编码绝对路径或 Agent 特定安装路径。
- 可执行逻辑集中在 `scripts/` 目录下，按职责拆分为多个脚本（如 `query.py` 分发器 + `query_mysql.py`/`query_postgres.py` 处理器），对外暴露单一 CLI。
- 参考文档集中放在 `references/` 下，并按主题细分（如 `howto/`、`guide/`、`document/`），由 `SKILL.md` 中的交叉链接组织阅读顺序。
- 所有技能在末尾嵌入相同的 Feedback 步骤，通过调用 `.specify/scripts/python/feedback-utils.py --action record` 将运行反思提交给 Spec Kit 引擎。
- 复杂技能使用 `examples/` 或 `templates/` 提供可直接运行的示例或模板文件，使 Agent 能基于真实样例生成新内容。
