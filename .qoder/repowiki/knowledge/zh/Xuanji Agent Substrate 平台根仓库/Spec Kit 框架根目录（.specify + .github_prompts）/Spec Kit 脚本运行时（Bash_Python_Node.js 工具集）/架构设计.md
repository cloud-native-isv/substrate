模块按语言划分为三个并列子目录：`bash/` 存放纯 Shell 编排脚本（如 `implement-plan.sh`、`create-new-requirements.sh`、`research-project.sh`），统一通过 `source common.sh` 复用特征分支解析、UTF-8 环境、技能脚手架等公共函数；`python/` 提供轻量级 Python 工具（如 `gate-check.py` 基于内置 `fnmatch` 解析 `.specify/gate.yaml` 实现 deny/confirm/allow 三态门禁，以及 `docs-utils.py`、`skills-utils.py` 等面向仓库元数据的辅助脚本）；`js/better-harness/` 是独立的 ESM Node.js 子工程（`package.json` 声明 `type: module` 且限定 Node ≥22.20），内部以多个独立 CLI 子包组织：`session-analysis/` 通过顶层 `session-analysis.mjs` 暴露 `SessionAnalyzer` 抽象基类并按 `--platform` 动态 `import()` 加载 `platforms/{qoder,codex,claude,cursor,opencode}.mjs` 实现多平台会话解析；`agent-customize/`、`agent-lint/`、`coding-agent-practices/`、`core-change-watch/`、`dependency-governance/` 各自拥有独立入口（`cli.mjs` 或 `index.mjs`），彼此之间仅通过相对路径 import 共享 `session-analysis/cli.mjs` 等通用参数解析器。依赖方向严格自顶向下：CLI → 领域模块 → 平台/提供者实现，外部仅依赖 Node 标准库与可选的 Git/文件系统访问。
