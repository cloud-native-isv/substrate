- 每个可执行脚本均以 shebang 开头，并通过 `set -e` 或 try/catch 保证失败时非零退出码。
- Bash 脚本统一 `source "$SCRIPT_DIR/common.sh"` 后调用 `ensure_utf8_locale`，并使用 `safe_quote`、`validate_input`、`is_valid_utf8` 处理用户输入与 UTF-8 安全。
- Node.js CLI 采用 `parseArgs(argv)` 解析参数，并以 `if (isCli) main().catch(...)` 模式同时支持被 require 和直接运行。
- 多平台扩展通过动态 `import()` 按 `--platform` 选择具体实现（如 `session-analysis/platforms/*.mjs`），新增平台只需在路由表中注册对应 Analyzer 类。
- Python 工具遵循单职责文件命名（如 `gate-check.py`、`docs-utils.py`），并通过 `__file__` 相对定位仓库根目录，使脚本可在原始位置或被镜像复制后均能正确运行。
- 输出格式统一支持 JSON 模式：Bash 通过 `report_success/report_error` 的 `json_mode` 参数输出 `{status,message,...}`，Node 脚本默认 `console.log(JSON.stringify(payload))`。
