本模块是 Spec Kit 框架在仓库中的安装点，按职责将子模块分层组织：`agents/` 定义角色与执行实例，`skills/` 提供可复用能力，`templates/` 与 `.github/prompts/` 分别承载文档模板与 GitHub Prompts 格式的提示词，`scripts/` 提供 Bash/Python/Node.js 运行时引擎，`shared/` 维护跨子模块共享的概念定义与工作流约定，`memory/` 持久化特性、宪法、术语与知识索引。所有子模块通过 `.specify/instructions.md` 这一单一权威指令文件串联——它由 `/speckit.instructions` 命令根据 agents/skills/templates/shared 等目录内容生成，并通过符号链接同步到 `AGENTS.md`、`.github/copilot-instructions.md`、`CLAUDE.md`、`QWEN.md`、`QODER.md` 等 AI 工具兼容路径，使不同 Agent 以同一份规范消费全部资源。Agent 生命周期遵循 Template → Instance → Execution 三层模型，由 `agents/execution/configs` 与 `agents/execution/scripts` 驱动；技能通过 `SKILL.md` 声明并在 `skills/` 下注册；模板渲染由 `scripts/` 中的 Python/Bash 引擎调用；所有可复用资源（Agent/Skill/Tool）均登记在 `instructions.md` 末尾的资源注册表区域，供命令自动发现。
