本模块由两个互补目录组成：`.specify/templates/` 存放被 `/speckit.*` 命令在运行时复制并就地填充占位符（如 `[PLACEHOLDER]`）的输出模板，涵盖 plan.md、requirements.md、tasks.md、checklist-template.md、constitution-template.md、feature-details-template.md、feature-index-template.md、gate-template.yaml、glossary-template.md、skills-template.md、verification-log-template.md 及 .gitignore/.claudeignore/codexignore/vscode-settings.json 等工程脚手架；`.github/prompts/` 存放 `speckit.<command>.prompt.md` 形式的 AI 提示词，每个提示词对应一个 /speckit.* 命令的工作流，通过读取模板、项目记忆（`.specify/memory/`）、现有文档和代码库来生成或更新 `.specify/specs/<key>/` 下的产物。两者之间存在镜像关系——提示词中的注释表明其由 `scripts/python/regen-command-copies.py` 从 `templates/commands/` 自动同步到 `.github/prompts/`，因此模板是单一事实源，提示词是面向 LLM 的衍生副本。依赖方向单向：提示词 → 模板 → 输出文档，不反向引用代码实现。
