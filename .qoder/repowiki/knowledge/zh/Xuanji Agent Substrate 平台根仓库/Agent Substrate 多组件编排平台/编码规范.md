- 所有 gRPC 服务通过 internal/proto/*.proto 定义，经 protoc-gen-go 与 protoc-gen-go-grpc 生成 Go 代码，位于对应 pb 包中。
- 每个 cmd/* 下的二进制遵循 main.go → internal/ 子包分层结构，启动逻辑由 serverboot 统一初始化日志、追踪、指标与依赖。
- CRD 类型定义在 pkg/api/v1alpha1，配合 controller-gen 生成 zz_generated.deepcopy.go 与 clientset/informers/listers。
- 错误处理统一使用 internal/ateerrors 定义的 ATE 错误码与包装函数。
- 可观测性通过 internal/serverboot 注入 OpenTelemetry 上下文，所有 HTTP/gRPC 调用自动携带 trace/span。
