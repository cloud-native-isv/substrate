根模块以单一 go.mod 聚合多个独立二进制（cmd/*）与共享库（internal/*、pkg/*），各组件通过 gRPC + protobuf 协议通信：
- 控制面：atecontroller 监听 Actortemplate/SandboxConfig/WorkerPool CRD 变更并驱动集群状态；podcertcontroller 负责证书签发。
- API 面：ateapi 暴露 controlapi/actoridentity/debugapi 三个 gRPC 服务，统一由 serverboot 初始化日志、追踪、指标、Redis 与 K8s 客户端。
- 节点面：atelet 在每个节点上协调镜像拉取、OCI bundle 准备与外部卷挂载；ateom-gvisor/ateom-microvm 作为具体运行时后端。
- 网络面：atenet 提供 DNS 与基于 nftables 的流量路由。
- 共享层：internal/* 提供认证（ateapiauth、localjwtauthority）、gRPC 拦截器、隧道（atunnel）、镜像缓存（imagecache）、资源定义（resources）等横切能力；pkg/api/v1alpha1 定义 CRD 类型并由 controller-gen 生成 clientset/informers/listers。
- 部署与演示：manifests/* 使用 kustomize 组装安装清单；demos/* 与 benchmarking/* 提供示例与工作负载；hack/* 封装开发、验证与更新脚本。
