- 所有 gRPC 请求在进入业务逻辑前统一调用 validate*Request 函数进行字段校验，非法输入通过 status.Error(codes.InvalidArgument, ...) 返回。
- 错误分类使用 ateerrors.CrashIfReason 与 ateerrors.Reason* 常量标记可恢复/不可恢复错误，文件系统致命错误通过 wrapFileSystemErr 包装并标记为 ReasonTerminalFileSystemError。
- 并发任务统一使用 golang.org/x/sync/errgroup.WithContext 组织 goroutine，每个子任务独立携带 context 并在失败时快速传播。
- 对象存储访问通过 ategcs.ObjectStorage 接口抽象，GCS 与 S3 分别实现 GetObject/PutObject，并通过 streamingPutter 标记接口区分是否支持流式上传。
- OCI bundle 构建采用 overlay 模式：在 bundle 目录下创建 rootfs/upper/work 三目录，通过 imagecache.WriteSpec 写入 overlay 配置，实际挂载由 ateom 完成。
- 沙箱资产与快照采用自描述 manifest（manifest.json）持久化，记录 sandboxClass、content-addressed assets、actor 身份与 snapshotFiles，确保 Checkpoint/Restore 无需控制平面即可定位正确版本。
