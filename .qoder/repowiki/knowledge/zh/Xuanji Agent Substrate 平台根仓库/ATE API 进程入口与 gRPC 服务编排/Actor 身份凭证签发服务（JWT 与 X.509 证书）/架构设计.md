本模块由两个子包组成：
- `actoridentity`：实现 `ateapipb.ActorIdentityServer` gRPC 服务端，暴露 `MintJWT` 与 `MintCert` 两个 RPC。`MintJWT` 通过 `k8sjwt.Verify` 校验调用方的 Kubernetes ServiceAccount JWT，再使用 `localjwtauthority` 从磁盘加载的签名密钥池签发 actor JWT；`MintCert` 通过 mTLS 对 atelet 进行双向认证（SPIFFE URI 白名单 + PodIdentity 扩展），并依据 `store.Interface` 中的 Actor/Worker 元数据执行细粒度授权（节点归属、分配一致性检查），最终用本地 CA 池签发带 SPIFFE URI 的 X.509 客户端证书。
- `actoridjwt`：纯函数式 JWT 编解码与签名库，定义 `Claims`/`WireClaims` 结构体及 `ClaimsToWire`、`Sign` 方法，支持 RS256/RS384/RS512/ES256 算法，不依赖任何网络或存储。

依赖方向单向：`actoridentity` 依赖 `actoridjwt`、`k8sjwt`、`localca`、`localjwtauthority`、`substratex509`、`resources`、`store` 等内部包；`actoridjwt` 无外部依赖。密钥材料（actor ID JWT 签名池、CA 池）以文件形式按路径注入，当前未做内存缓存（代码中有 TODO）。
