- gRPC 错误统一通过 `status.Errorf(codes.Xxx, ...)` 返回，区分 Unauthenticated、PermissionDenied、InvalidArgument、FailedPrecondition、Internal 等语义。
- 鉴权失败日志使用 `slog.WarnContext` 记录拒绝原因与上下文信息，而内部错误使用 `slog.ErrorContext`，保持可观测性一致。
- 敏感操作（如证书签发、JWT 签发）在调用前严格校验输入参数为空或类型不匹配时直接返回 InvalidArgument，避免后续 panic。
- 权限判定采用 deny helper 模式：将不同拒绝原因统一映射为相同的 PermissionDenied 状态码，防止枚举攻击泄露存在性信息。
- Actor 引用统一使用 `resources.ActorRef{Atespace, Name}` 结构体传递，避免分散的字符串拼接。
