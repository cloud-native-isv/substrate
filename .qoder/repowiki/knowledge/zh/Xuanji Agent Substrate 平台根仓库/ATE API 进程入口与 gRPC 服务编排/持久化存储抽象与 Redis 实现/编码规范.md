- 所有错误通过包级变量统一暴露（`ErrNotFound`、`ErrAlreadyExists`、`ErrVersionConflict`、`ErrFailedPrecondition`、`ErrLockConflict`），实现层将 `redis.Nil` 等底层错误映射为这些语义化错误。
- 写入操作一律先 `proto.Clone` 输入参数再填充服务端元数据（uid、version、timestamps），确保不修改调用方传入的对象。
- 更新操作使用 `rdb.Watch` 事务配合 `expectedVersion` 实现乐观并发控制，冲突时返回 `ErrVersionConflict`。
- 分页 List 方法统一通过 `listPage` + `pageToken`（base64 编码的 shardHash+cursor）实现跨 Redis 分片的稳定分页。
- Key 命名由独立的 `*DBKey` 函数集中生成（如 `actorDBKey`、`workerDBKey`、`atespaceDBKey`），保证键空间一致性且便于 SCAN 模式匹配。
- Worker 状态变更通过 Redis Pub/Sub 通道 `worker-changes` 广播，`WatchWorkers` 返回带缓冲 channel 的 `WorkerWatch`，由调用方 `Close()` 释放订阅。
