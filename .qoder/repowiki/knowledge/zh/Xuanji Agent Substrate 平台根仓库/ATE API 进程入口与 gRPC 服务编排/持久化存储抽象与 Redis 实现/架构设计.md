模块采用「接口 + 具体后端」的分层设计：
- `store.go` 定义核心契约 `store.Interface`，涵盖 Actor/Atespace/Worker/ActorSnapshot/Tag 的 CRUD、分页 List、分布式锁 `AcquireLock`、`WatchWorkers` 事件订阅以及 `DebugClearAll` 调试能力；同时提供 `WorkerWatch`、`Lock`、`WorkerEvent` 等共享类型。
- `ateredis/` 是 Redis Cluster 后端实现（`Persistence` 结构体），通过 `redisClient` 接口屏蔽底层客户端差异，使用 `protojson` 将 Protobuf 对象序列化为 JSON 存入 Redis Key，Key 命名遵循 `actor:<atespace>:<name>`、`worker:<namespace>:<pool>:<pod>`、`actor-snapshot:*`、`actor-snapshot-tag:*`、`atespace:*` 等固定前缀。
- `storetest/` 提供基于 `miniredis` 的测试辅助函数 `SetupTestStore`，让单元测试直接复用真实 Redis 后端逻辑。
- 依赖方向单向：`ateredis` → `store`（实现接口）→ 上层调用者仅依赖 `store.Interface`，可替换后端。
