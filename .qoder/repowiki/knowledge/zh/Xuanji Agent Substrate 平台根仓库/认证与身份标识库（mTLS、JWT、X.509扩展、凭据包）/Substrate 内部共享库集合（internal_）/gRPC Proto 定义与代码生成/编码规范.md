- 每个 proto 包独立一个目录，包含 `.proto`、生成的 `.pb.go`、`_grpc.pb.go` 以及仅含 `//go:generate` 指令的 `gen.go`。
- 所有 `.proto` 文件使用 `syntax = "proto3"`，并通过 `option go_package` 指定完整的 GitHub module 路径作为 Go 输出包名。
- 请求/响应消息成对命名：`*Request` 对应 `*Response`，且 Response 通常为空结构体。
- 枚举类型以 `*_UNSPECIFIED = 0` 作为默认值开头，符合 proto3 规范。
- 可选字段通过 `optional` 关键字声明（如 `egress_gateway_address`、`golden_snapshot_uri_prefix`），而非 protobuf-wrappers。
- 向后兼容通过 `reserved` 保留已废弃字段编号及名称（如 ateom.proto 中 reserved 字段 3 与 `durable_dir_volumes`）。
