模块按功能拆分为三个独立的 proto 包：
- `ateletpb`：定义 AteomHerder 服务，供控制面编排 atelet（容器生命周期管理）。
- `ateompb`：定义 Ateom 服务，暴露单个 gVisor/microVM 工作负载的 RunWorkload/CheckpointWorkload/RestoreWorkload 能力。
- `glutton`：定义 Glutton 基准测试服务的 RAM/Disk/FD/Ping/Gossip 接口。

每个子目录遵循统一结构：`.proto` 源文件 + 对应的 `.pb.go` / `_grpc.pb.go` 生成产物 + `gen.go` 中的 `//go:generate` 指令。生成过程通过 `../../../hack/protoc.sh` 包装脚本调用 `protoc-gen-go` 与 `protoc-gen-go-grpc`，并使用 `paths=source_relative` 保持 Go package 路径与仓库布局一致。依赖方向单向向下：上层业务仅依赖生成的 `*.pb.go`，不直接触碰 `.proto` 文件。
