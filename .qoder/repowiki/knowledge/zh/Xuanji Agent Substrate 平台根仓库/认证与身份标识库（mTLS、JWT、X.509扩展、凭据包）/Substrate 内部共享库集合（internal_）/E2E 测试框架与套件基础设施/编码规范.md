- 每个 e2e 套件必须实现 `TestMain` 并调用 `e2e.RunTestMain`，在 `run` 函数中包裹 `Setup()` 与 `defer Teardown()` 完成组件级生命周期管理。
- 测试中通过 `GetClients()` 获取共享的 `Clients` 结构体访问 K8s 与 ATE API，禁止自行构造客户端。
- 需要隔离资源时使用 `CreateNamespace(t)` 创建带 `ate.dev/e2e=true` 标签的随机命名空间，并由框架在成功时自动清理、失败时保留。
- 外部命令执行统一通过 `RunCmd` / `RunCmdWithEnv` 包装，自动将 stdout/stderr 着色并以缩进输出，失败时直接 `t.Fatalf`。
- 用户可见输出通过 `Colorf` / `FColorf` 使用 `<tag>...</tag>` 标记语法渲染 ANSI 颜色，且受 `--no-color` 与 `NO_COLOR` 环境变量控制。
