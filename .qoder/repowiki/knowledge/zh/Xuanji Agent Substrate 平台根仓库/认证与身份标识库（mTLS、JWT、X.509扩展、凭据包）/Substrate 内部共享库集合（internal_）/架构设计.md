internal/ 是一个扁平的 Go package 集合，子包之间遵循单向依赖：proto/ 定义跨组件 gRPC 接口；auth_identity（ateapiauth、ateattr、credbundle、principal、substratex509、localca、localjwtauthority）提供 mTLS/JWT/X.509 认证链，被 ateinterceptors、serverboot 消费；networking（ateomnet、atunnel、portforward）在 ateom 与 atelet 之间提供 nftables egress 重定向与 mTLS CONNECT 隧道；imagecache 为每个 actor 组装 overlayfs rootfs，volume 提供卷插件抽象；actor_runtime_libs（actorlog、contextlogging、readyz、version、resources、benchmarking、envtestbins、roottest）为所有长进程提供日志、指标、追踪、健康检查、K8s 客户端构建等通用能力；e2e/ 独立于业务逻辑，复用上述库编写端到端套件。各子包彼此不互相依赖或仅单向引用，由上层二进制组合调用，形成「协议 → 认证 → 网络 → 存储 → 运行时」的分层协作关系。
