本模块由一组彼此独立、面向特定横切关注点的 internal 子包组成，按职责划分而非分层：
- 可观测性基础设施：`serverboot` 统一初始化 slog（经 `contextlogging` 注入 trace-id）、OTel TracerProvider/MeterProvider、Prometheus /metrics 以及 /readyz 和可选 /healthz HTTP 端点；`readyz` 在 ateom 内以毫秒级间隔轮询容器 HTTP 就绪端点。
- gRPC 横切面：`ateinterceptors` 提供服务端拦截器（记录请求/响应、附加服务器耗时 trailer、强制最大超时）；`ateerrors` 定义 AIP-193 风格的 Reason 枚举并通过 `NewGRPCError` 构造带 ErrorInfo 的 gRPC status，配合 `CrashIfReason` 实现按原因分类的 actor 崩溃指令。
- 客户端与认证：`ateclient` 通过 `NewClient` 自动选择直连或 port-forward 到 ate-api-server，使用 ClusterTrustBundle 验证 TLS、ServiceAccount TokenRequest 作为 per-RPC 凭据，并可选启用 OTel 客户端拦截。
- 资源与路径契约：`resources` 定义 ActorRef、网络策略校验等共享类型；`ateompath` 集中定义 ateom/atelet 共用的文件系统路径（BasePath=/var/lib/ateom-gvisor 下的 actors、bundles、runsc-state 等）；`version` 通过 ldflags 注入版本信息并在 init 中回退到 runtime/debug.ReadBuildInfo。
- 安全与存储抽象：`localca` 提供基于 ED25519 的本地 CA（支持序列化/反序列化），`volume` 定义控制平面与 worker 平面的 VolumePlugin 接口。
- 测试与基准：`envtestbins` 通过文件锁串行化 setup-envtest 下载；`roottest` 标记需要 root 权限的测试；`benchmarking/boomer/glutton` 是 Go 重写的 locust GluttonUser 负载，通过 ateinterceptors 的 server elapsed trailer 获取真实服务器延迟。
依赖方向单向向下：各包仅依赖更底层的共享类型（如 resources、proto），不存在循环依赖。
