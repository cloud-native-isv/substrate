- gRPC 错误统一通过 `ateerrors.NewGRPCError` 构造，携带 AIP-193 ErrorInfo（Domain=substrate.dev、Reason 枚举、Metadata），并由调用方用 `CrashIfReason` 声明哪些 Reason 应触发 actor 崩溃。
- OpenTelemetry 属性键集中在 `ateattr` 包中以 `attribute.Key` 形式定义（如 `ate.atespace`、`ate.actor.name`、`ate.worker.state`），禁止在各处硬编码字符串常量。
- 服务启动流程遵循 `serverboot.InitLogger` → `InitTracing` → `InitMetrics` → `StartMetricsServer` 的顺序，并通过 `ShutdownProvider` defer 关闭 provider。
- 所有内部 gRPC 服务端拦截器都通过 `sanitizeForLog` 克隆 proto.Message 并清除 `env` 字段后再写入日志，防止敏感环境变量泄露。
- 路径常量统一通过 `ateompath` 包的函数生成（如 `AteomPath`、`ActorPath`、`OCIBundlePath`），禁止在业务代码中拼接 BasePath。
- HTTP 客户端与外部依赖通过包级 var 暴露（如 `readyz.HTTPClient`、`ateclient` 中的 dial 函数），便于测试替换为 mock 或 loopback 目标。
