模块按 atelet/ateom 权限边界拆分为两个编译片段：
- 通用部分（imagecache.go、unpack.go、spec.go、sizes.go、implicitdirs.go、retire.go、removeall.go）在 atelet 中运行，负责解析引用、并发拉取并解压层到 `layers/sha256/<diffid>/fs/`，记录 manifest 到 `manifests/sha256/<digest>.json`，以及生成 bundle 的 `rootfs-overlay.json` 规格。
- Linux 专属部分（bundle_linux.go，`//go:build linux`）在特权 ateom 容器中运行，负责 FinalizeLayer（白名单/不透明目录物化）、通过新 mount API（`fsopen` + `lowerdir+`）挂载 overlayfs，以及 `UnmountAllUnder` 清理挂载。
- 核心数据结构 Store 使用 singleflight.Group 对同 digest 的 image/layer 拉取做去重，errgroup 限制并发为 4；所有磁盘写操作采用 temp 文件 + rename 原子提交，启动时 sweepTempDirs 恢复崩溃残留。
- 依赖方向单向：bundle_linux.go 依赖 spec.go/unpack.go 定义的接口，但通用代码不反向依赖 Linux 特定逻辑，通过 build tag 隔离。
- 与外部交互仅通过文件系统（共享 cache-root hostPath），无 RPC/进程间通信。
