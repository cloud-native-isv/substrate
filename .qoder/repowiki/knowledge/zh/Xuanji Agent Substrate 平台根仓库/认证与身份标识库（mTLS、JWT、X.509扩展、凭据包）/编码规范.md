- 每个功能包都采用单文件实现加同名 `_test.go` 单元测试的组织方式，包注释以 `// Package xxx ...` 开头说明职责。
- 错误信息统一使用 `fmt.Errorf("包名: 描述: %w", err)` 格式包装，便于调用方识别错误来源。
- 上下文传递主体信息遵循 `InjectContext(ctx, PrincipalInfo)` 与 `FromContext(ctx)` 的配对模式，使用私有 contextKey 避免键冲突。
- X.509 自定义扩展通过 ASN.1 ObjectIdentifier 下挂 GoogleSubstrate PEN 命名空间，并以 JSON 编码扩展值而非 ASN.1。
- 需要频繁读盘的资源（证书、令牌）均采用“首次解析+stat 变更检测”的缓存模式，保证 pod 证书轮换时下一握手即生效。
