根目录作为 github.com/agent-substrate/substrate 单 Go Module，将所有子模块（ate_controller、ate_api_server、atelet、atenet、pod_cert_controller、kubectl-ate、ateom_gvisor、ateom_microvm、crds_and_clients、kubernetes_manifests、demos、benchmarking、dev_tools、documentation）组织在同一仓库中。cmd/* 下的二进制入口由 Makefile 的 build-images / build-atectl 目标统一用 Ko 或 go build 编译；crds_and_clients 通过 controller-gen/client-gen/informer-gen 生成 CRD 与 clientset，被 ate_controller、ate_api_server、pod_cert_controller 共同消费；internal/*（shared_internal_libs）提供认证身份、gRPC Proto、网络隧道、镜像缓存、E2E 框架等横切能力，被 atelet、ateom_gvisor、ateom_microvm、atenet、ate_controller 等多个子模块依赖；kubernetes_manifests 使用 Kustomize 将上述组件打包为可组合的部署变体。各组件通过 gRPC（protobuf 定义在 crds_and_clients 中）与 Kubernetes API Server 通信，并由 ate_api_server 作为统一入口暴露 controlapi/actoridentity/debugapi 三个服务。
