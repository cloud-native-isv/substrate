本模块由两类子项目组成：
- `tools/` 下是独立的 Go CLI 工具，每个工具以 `main.go` 为入口，通过 `cmd/` 子包组织 cobra 命令树（如 `setup-gcp` 按功能拆分为 `cluster.go`、`bucket.go`、`iam.go`、`dashboards.go` 等命令文件，共享 `common.go` 配置）。`validate-image-cache` 直接调用仓库内 `internal/imagecache` 包对 OCI 镜像进行批量拉取、解压与缓存验证。
- `hack/` 下是纯 shell 脚本与第三方工具的 go.mod 锁定目录。`hack/tools/<tool>/go.mod` 使用 `tool <module>` 指令精确锁定 controller-gen、ko、golangci-lint、protoc-gen-go 等依赖版本；`update-all.sh` 与 `verify-all.sh` 作为统一入口，分别遍历 `hack/update/*.sh` 与 `hack/verify/*.sh` 执行代码生成、格式化、许可证检查、shellcheck 等步骤。`run-tool.sh` 配合 `kind.sh`、`protoc.sh` 等将具体工具封装为可复用的命令。
- 依赖方向单向：工具只依赖仓库内的 `internal/*` 或标准库/外部库，不反向依赖业务代码；脚本之间通过 `ROOT=$(git rev-parse --show-toplevel)` 定位仓库根，保持无状态可移植性。
