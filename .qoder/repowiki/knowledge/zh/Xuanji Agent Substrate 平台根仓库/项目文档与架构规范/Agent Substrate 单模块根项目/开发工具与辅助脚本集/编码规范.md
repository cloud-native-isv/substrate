- Go 工具入口 `main.go` 仅负责解析错误并调用 `cmd.Execute()`，实际命令逻辑全部放在 `cmd/` 子包中，便于拆分多命令结构。
- Shell 脚本统一以 `set -o errexit -o nounset -o pipefail` 开头，并通过 `ROOT=$(git rev-parse --show-toplevel)` 定位仓库根路径，保证跨环境一致性。
- 第三方工具依赖通过 `hack/tools/<tool>/go.mod` 单独声明并使用 `tool <module>` 指令锁定，避免污染主模块依赖。
- CLI 命令参数优先从环境变量读取默认值（如 `getEnv("PROJECT_ID", "")`），再允许命令行覆盖，保持配置与环境解耦。
