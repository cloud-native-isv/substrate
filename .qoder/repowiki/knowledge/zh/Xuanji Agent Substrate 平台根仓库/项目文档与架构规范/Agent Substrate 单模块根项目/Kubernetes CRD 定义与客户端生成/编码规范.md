- CRD 类型通过 kubebuilder 注解（如 `+kubebuilder:object:root=true`、`+kubebuilder:validation:XValidation`、`+groupName=ate.dev`）声明 OpenAPI v3 校验与元数据，而非手写 Validate 方法。
- 每个 CRD 类型配套一个同名的 `*_validation_test.go` 文件，使用 kubebuilder 提供的测试框架验证 XValidation 规则。
- 所有生成代码顶部带有 `// Code generated by ... DO NOT EDIT.` 注释，手动修改会被覆盖，变更需回到源定义或 gen.go。
- go:generate 指令统一通过 `../../../hack/run-tool.sh` 包装外部二进制，保证工具版本一致性。
- gRPC 消息使用统一的 `ResourceMetadata` 结构承载 atespace/name/uid/version/timestamp 等公共字段，保持跨资源的身份模型一致。
