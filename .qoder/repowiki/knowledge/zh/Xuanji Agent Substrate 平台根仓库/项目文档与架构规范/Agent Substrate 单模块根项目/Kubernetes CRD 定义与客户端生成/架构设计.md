模块按职责分为三个子目录：
- `pkg/api/v1alpha1/`：使用 kubebuilder 注解声明 CRD 类型（ActorTemplate、SandboxConfig、WorkerPool），通过 `groupversion_info.go` 注册 GroupVersion `ate.dev/v1alpha1`，并由 `zz_generated.deepcopy.go` 提供 DeepCopy 实现。
- `pkg/client/`：由 client-gen、lister-gen、informer-gen 生成的 Kubernetes 客户端层，包含 `clientset/versioned`（REST 客户端）、`listers/api/v1alpha1`（缓存只读访问）和 `informers/externalversions`（SharedInformerFactory + 各资源 Informer），依赖 `k8s.io/client-go` 的 cache 机制。
- `pkg/proto/ateapipb/`：基于 `ateapi.proto` 定义的 Control、Debug、ActorIdentity 三个 gRPC service，通过 protoc 生成 Go 代码。

代码生成入口集中在两个 `gen.go` 文件中：`pkg/api/v1alpha1/gen.go` 通过 go:generate 调用 controller-gen 输出 CRD YAML 到 `manifests/ate-install/generated/`，并再生成 clientset/listers/informers；`pkg/proto/ateapipb/gen.go` 调用 `protoc.sh` 生成 `.pb.go` 和 `_grpc.pb.go`。依赖方向单向：proto → pb 代码，CRD types → client/lister/informer 代码，运行时组件仅消费这些生成产物，不反向依赖。
