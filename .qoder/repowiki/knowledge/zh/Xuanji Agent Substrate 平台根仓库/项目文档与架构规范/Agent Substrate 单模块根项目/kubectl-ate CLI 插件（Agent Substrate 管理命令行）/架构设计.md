模块以 `main.go` 为唯一入口，仅调用 `cmd.Execute()`；核心命令树由 `internal/cmd/root.go` 中的 Cobra root 命令组织，每个子命令（get、create、delete、admin、logs、top、workers、pause/resume/suspend 等）各自独立文件并在 `init()` 中通过 `rootCmd.AddCommand` 注册，形成扁平且可组合的命令结构。输出格式化逻辑完全下沉到 `internal/printer` 包，按 `--output`（table/json/yaml）统一渲染 protobuf 响应，避免命令层直接处理序列化。全局持久化标志（kubeconfig、context、endpoint、output、trace）在 root 命令上集中声明，通过 `PersistentPreRunE` 做格式校验。依赖方向单向：`main → cmd → printer`，不反向依赖；对外通过 gRPC 客户端（由 `--endpoint` 或自动 port-forward 决定目标）访问 Substrate 控制平面，Actor/Worker 状态实际存储在 Redis/Valkey 而非 Kubernetes etcd。
