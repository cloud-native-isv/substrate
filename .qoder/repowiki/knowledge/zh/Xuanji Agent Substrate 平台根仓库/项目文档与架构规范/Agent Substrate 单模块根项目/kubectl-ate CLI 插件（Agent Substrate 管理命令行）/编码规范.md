- 每个子命令单独一个文件，并在 init() 中通过 rootCmd.AddCommand 注册，保持命令定义与实现一一对应。
- 所有输出统一走 `internal/printer` 包的 PrintXxx 函数族，按 table/json/yaml 三种格式分支处理，命令层不直接操作 io.Writer。
- 列表型打印函数遵循 sort → switch(format) → tabwriter/tablewriter 的模式，并按字段顺序使用 slices.SortFunc 排序。
- JSON/YAML 输出通过 printProto 统一将 protobuf 消息经 protojson 序列化后再转 YAML，确保输出一致性。
- 全局标志集中在 root.go 的 PersistentFlags 中声明，并通过 PersistentPreRunE 进行集中校验（如 output 格式白名单）。
