每个子目录是一个自包含的演示，遵循统一模式：一个 Go/Shell 工作负载 + 一份 `*.yaml.tmpl` Kubernetes 清单模板（由 `./hack/install-ate.sh` 通过 `envsubst` 注入 `BUCKET_NAME` 等环境变量后部署）+ README 文档。演示之间相互独立，不共享代码，仅通过根目录的 `hack/install-ate.sh` / `hack/install-ate-kind.sh` 脚本统一编排安装与卸载。核心依赖包括：ko 构建镜像、GCS 快照存储、kubectl-ate CLI 管理 ActorTemplate/WorkerPool/Actor 资源、atenet Router 路由流量。部分演示扩展了额外组件：autoscaled-workerpool 引入 prometheus-adapter + HPA；claude-code-multiplex 提供 Go UI 和 Dockerfile 工作负载；multi-template 使用 fspersist 包演示跨命名空间共享池；parking 附带 load.sh 压测脚本。
