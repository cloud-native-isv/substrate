- 每个演示目录包含一个 `*.yaml.tmpl` 清单模板，由安装脚本在部署时注入 `${BUCKET_NAME}` 等环境变量，禁止手动编辑模板文件。
- Actor 必须先在 atespace 中创建（`kubectl ate create atespace <name>`），再基于 ActorTemplate 创建具体 Actor。
- 通过 `kubectl port-forward -n ate-system svc/atenet-router 8000:80` 暴露 Router，再以 `<actor-id>.<atespace>.actors.resources.substrate.ate.dev` 作为 Host 头访问。
- 演示通过 `ko` 构建镜像并推送到 `${KO_DOCKER_REPO}`，镜像引用在模板中解析为 sha256 固定版本。
- 状态持久化统一通过 GCS 快照实现，Actor 挂起/恢复时由 Substrate 自动完成快照读写。
