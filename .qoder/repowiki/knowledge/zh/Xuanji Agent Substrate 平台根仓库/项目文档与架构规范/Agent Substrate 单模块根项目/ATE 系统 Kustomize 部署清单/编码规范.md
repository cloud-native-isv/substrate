- 所有 Kustomization 文件顶部保留 Google LLC Apache 2.0 许可证头注释。
- Overlay 通过 inline JSON Patch 修改容器 args/env，并使用 `op: test` 先校验参数位置再执行 `remove/add/replace`，确保构建失败时能定位基线变更。
- 组件化扩展统一放在 `components/<name>/kustomization.yaml` 中，以 `kind: Component` 声明并通过 `components:` 字段被 overlay 引用。
- Kind 开发环境通过集中式 patch 注入 OTEL_EXPORTER_OTLP_ENDPOINT、OTEL_METRIC_EXPORT_INTERVAL/TIMEOUT 等环境变量，使所有组件统一上报到集群内 OpenTelemetry Collector。
- 认证相关覆盖（如 token-client）将 ServiceAccountToken 和 ClusterTrustBundle 通过 projected volume 挂载到固定路径（/run/ateapi-token、/run/servicedns-ca），保持与证书路径一致的挂载约定。
