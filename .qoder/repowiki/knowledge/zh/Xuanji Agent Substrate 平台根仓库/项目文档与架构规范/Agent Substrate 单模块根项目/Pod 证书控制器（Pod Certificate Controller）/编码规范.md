- 每个签名器通过实现 `signercontroller.SignerImpl` 接口（SignerName / DesiredClusterTrustBundles / MakeCert）来注册自身，并由 controller 根据 SignerName 路由请求。
- 证书生命周期统一设置 NotBefore = now - 2min、NotAfter = NotBefore + 24h（或更短的 MaxExpirationSeconds）、BeginRefreshAt = NotAfter - 30min，并通过 UpdateStatus 写回 PCR 状态。
- 所有错误通过 fmt.Errorf 包装原始错误返回，由上层统一 slog.ErrorContext 记录 key 与 err，保持日志一致性。
- 多副本协作通过 rendezvous.Hasher.AssignedToThisReplica 判断是否处理某 item，未分配时返回 rendezvous.ErrNotAssigned 触发带退避的重入队。
- ClusterTrustBundle 的创建/更新遵循 Get → Create 或 DeepEqual 比较后再 Update 的模式，避免不必要的写操作。
- 公共函数与常量通过包级变量暴露（如 Name、CTBPrefix），测试文件与实现文件同目录配对（*_test.go）。
