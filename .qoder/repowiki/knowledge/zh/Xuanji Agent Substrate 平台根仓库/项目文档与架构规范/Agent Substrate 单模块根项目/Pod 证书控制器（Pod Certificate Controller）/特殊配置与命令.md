启动需传入两个 CA pool 文件路径：`--service-dns-ca-pool` 与 `--pod-identity-ca-pool`，由 `localca.Unmarshal` 反序列化为 CA 池；多副本部署时需配置 `--sharding-pod-namespace`、`--sharding-pod-name`、`--sharding-pod-uid`、`--sharding-application-name` 以便 rendezvous 基于 Lease 分片。支持 `--in-cluster` 或 `--kubeconfig` 连接 API Server，`--version` 打印版本后退出。
