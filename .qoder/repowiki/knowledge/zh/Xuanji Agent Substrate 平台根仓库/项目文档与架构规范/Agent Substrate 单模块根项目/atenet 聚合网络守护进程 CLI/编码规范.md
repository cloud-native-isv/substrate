- CLI 命令通过 Cobra 定义，每个子模块暴露 `NewXxxCmd()` 工厂函数并在 `init()` 中 `rootCmd.AddCommand(...)` 注册。
- 长生命周期服务使用 `errgroup.WithContext(ctx)` 管理 goroutine 生命周期，配合 `context.Context` 实现优雅关闭。
- 日志统一使用 `log/slog` 的 `InfoContext`/`ErrorContext`/`DebugContext` 方法，并附带结构化字段而非拼接字符串。
- 错误包装统一使用 `fmt.Errorf("...: %w", err)` 形式，保持错误链可追溯。
- 对外部依赖（如 atStore、ConfigReloader）通过 interface 抽象并由构造函数注入，便于测试替换。
