入口 `main.go` 仅调用 `internal.Execute()`，由 `root.go` 构建 Cobra 根命令并在 `init()` 中注册 `router.NewRouterCmd()` 和 `NewDnsCmd()`，形成清晰的 CLI 分层。
- `internal/router`：核心路由子系统，`RouterServer` 在 `Run()` 中通过 `errgroup.WithContext(ctx)` 并发启动数据平面（xDS、Envoy Runner、ExtProc gRPC）、健康检查、HTTP `/statusz` 端点，并通过 ateapi gRPC 与 Control Plane 通信；配置来源支持 Kubernetes CRD（默认）或本地 YAML 文件（`--actor-templates-file`），通过 `atStore` 接口抽象。
- `internal/dns`：DNS 控制器，周期性 reconcile `atenet-router` 与 `dns` Service 的 ClusterIP，生成 CoreDNS Corefile 写入共享卷并通过 SIGUSR1 触发 CoreDNS 热重载，同时维护 kube-system/kube-dns ConfigMap 中的 stubDomains。
- 依赖方向单向：`main → internal/root → {router, dns}`，各子模块之间无直接耦合，均通过外部 k8s API 或服务发现交互。
- 可观测性统一通过 `serverboot` 初始化 Tracing/Metrics，并使用 OpenTelemetry gRPC/HTTP 插桩。
