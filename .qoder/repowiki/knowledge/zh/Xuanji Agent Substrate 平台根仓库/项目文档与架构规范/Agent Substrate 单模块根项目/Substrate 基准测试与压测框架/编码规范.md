- 所有 Python 文件顶部包含统一的 Apache 2.0 许可证头注释。
- Shell 脚本统一使用 `set -o errexit -o nounset -o pipefail` 严格模式，并通过 `git rev-parse --show-toplevel` 定位根目录。

- 日志输出采用带前缀的 TEE 模式（`[locust]` / `[boomer]`），并通过正则从 stdout 中抽取 trace_id、duration_ms 等结构化记录写入独立的 TSV 文件。
