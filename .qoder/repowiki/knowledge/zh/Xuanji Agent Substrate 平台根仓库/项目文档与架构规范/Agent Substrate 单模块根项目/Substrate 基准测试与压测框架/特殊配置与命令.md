部署需先 source `.ate-dev-env.sh` 设置 PROJECT_ID、BUCKET_NAME 等环境变量；使用 `./benchmarking/deploy_locust.sh --deploy [--worker-count N] [--skip-build]` 一键部署，`--delete` 反向清理；开发时需创建 venv 并运行 `benchmarking/locust/generate_protos.sh` 重新生成 Python gRPC 客户端；可通过 `kubectl port-forward svc/locust -n benchmarking 8089:8089` 访问 Web UI 手动触发测试。
