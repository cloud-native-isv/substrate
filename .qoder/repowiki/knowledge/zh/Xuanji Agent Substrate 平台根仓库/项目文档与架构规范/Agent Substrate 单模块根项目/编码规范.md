- 所有 Go 二进制入口位于 cmd/* 目录下，通过 go.mod 单模块引用 internal/* 共享包
- Kubernetes CRD 与客户端代码通过 controller-gen/client-gen/informer-gen 自动生成，禁止手写
- 镜像构建统一使用 Ko，并通过 LDFLAGS 注入 VERSION_PKG.Version 版本号
- gRPC 接口定义集中在 protobuf 文件中，由 crds_and_clients 模块生成 Go 客户端供各组件复用
- 验证与格式化通过 hack/verify/*.sh 与 ./hack/update/*.sh 脚本集中管理，Makefile 仅做转发
