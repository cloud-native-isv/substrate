模块为 Linux-only 的 Go 可执行程序，入口 `main.go` 启动 gRPC 服务器并注册 `AteomService`，内部按职责拆分为多个子包：
- `internal/ch`：cloud-hypervisor REST API 客户端（`api.go` 通过 unix socket HTTP 传输），封装 pause/snapshot/resume/shutdown 等生命周期操作。
- `internal/kata`：绕过 kata shim 直接驱动 kata-agent（ttrpc over hybrid-vsock），负责生成 `configuration.toml`、组装 overlay rootfs、管理 virtiofsd 以及清理沙箱状态。
- `internal/reaper`：集中式子进程回收器，用读写锁协调 SIGCHLD 收集与同步 exec.Cmd 的 wait，避免抢占导致 `waitid: no child processes`。
- `internal/tarutil`：tar/fifo/owner 等跨平台工具，Linux 下使用 syscall 优化。
- `internal/third_party/kata/agentpb`：kata agent 的 protobuf 定义（agent/oci/csi/types），由外部依赖生成。
顶层文件按功能划分：`run.go` 实现冷启动流程（构建 OCI bundle、启动 CH VMM + virtiofsd、配置 guest 网络、启动 overlay 容器）、`checkpoint.go` 实现 FULL/DATA 两种快照范围、`restore.go` 处理 OnDemand 恢复与 FD 传递、`net.go` 管理 veth/tap/netns、`spec.go` 将 OCI spec 转换为 kata 兼容格式、`durable.go` 处理持久化目录卷。依赖方向严格单向：`main` → `ch`/`kata`/`reaper`/`tarutil`，各子包不反向依赖顶层。
