- 所有对外部 `runsc` 二进制的调用都通过 `exec.CommandContext` 构造命令，统一附加 `-log-format json --alsologtostderr -root <stateDir>` 参数，并将 stdout/stderr 重定向到日志管道。
- 每个 gRPC 方法在执行前获取 `s.lock` 互斥锁，确保同一时刻只有一个工作负载操作在运行，避免并发修改 runsc 状态。
- 路径与文件位置全部通过 `ateompath` 包的函数生成（如 `AteomPath`、`OCIBundlePath`、`RunSCStateDir`、`PIDFilePath`），禁止硬编码路径字符串。
- 资源清理采用 defer 闭包配合 `retErr` 返回值判断的模式：在成功路径正常返回，在失败路径中尽力卸载 overlay rootfs、清理网络命名空间、删除 runsc 容器。
- 日志输出统一使用 `slog.InfoContext/WarnContext/ErrorContext`，并通过 `actorlog.ActorLogger` 的 `EmitLifecycleLog` 记录 actor 生命周期事件，包含 atespace、名称、UID、模板名等上下文字段。
- 可选功能（如 atunnel 入站/出站代理）通过 nil 检查分支处理，`activateActorNetworking`/`deactivateActorNetworking` 分别对 ingress 与 egress 独立调用并使用 `errors.Join` 聚合错误。
