- API 风格遵循 Google AIP（API Improvement Proposals），对标准方法（Get/List/Create/Update/Delete）和自定义方法（SuspendActor、ResumeActor 等）有明确的命名和资源标识约定
- Go 代码风格以 Effective Go 和 Google Go style guide 为基础，测试仅使用标准库 testing，采用 table-driven 测试模式配合 t.Run 子测试
- Proto 字段必须使用 lower_snake_case，枚举值使用 UPPER_SNAKE_CASE 并以枚举名作为前缀，零值统一为 _UNSPECIFIED
- 所有资源通过 ResourceMetadata 消息包含 atespace 和 name 两个字段作为唯一标识，ObjectRef 用于跨资源引用
- TODO 注释采用 TODO(<issue-number>): 格式，将待决策事项与具体 GitHub issue 关联
